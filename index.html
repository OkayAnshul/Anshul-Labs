Projects and experiments

A few open-source projects from the Anshul Labs GitHub — Android applications built around privacy and local-first design, alongside research into AI agents.

  • Android · Privacy Open source

    Voyager

    Privacy-first travel intelligence for Android. Reconstructs your day from raw GPS through a nine-stage on-device pipeline — no Maps API key, no account, no server.

    • Kotlin
    • Jetpack Compose
    • OpenStreetMap
    • SQLCipher
    View Voyager on GitHub
  • Android · On-device AI Open source

    Axiom

    A journal you talk to, with a companion that remembers. Local-first Android app — no account, no server, nothing leaves the phone.

    • Kotlin
    • Jetpack Compose
    • Room
    • On-device LLM
    View Axiom on GitHub
  • Android · Productivity Open source

    Kosmos

    An offline-first Android collaboration app that brings project workspaces, tasks and chat together, with realtime sync through Supabase.

    • Kotlin
    • Jetpack Compose
    • Room
    • Supabase
    View Kosmos on GitHub
  • Android · Productivity Open source

    DocAction

    Turns a timetable into calendar events, entirely on the phone. Deterministic on-device extraction with no network permission and no account.

    • Kotlin
    • Jetpack Compose
    • OCR
    • PDF extraction
    View DocAction on GitHub
  • AI / Research Experimental

    AMOS

    An autonomous multi-agent system: goal decomposition, specialised agents, tool execution, RAG and durable orchestration — built in independently useful vertical slices.

    • Python
    • LLM agents
    • RAG
    View AMOS on GitHub
  • AI / Experiment Experimental

    Custodian

    Exploring a purpose layer for agentic commerce: checking that an AI buyer purchased what the person actually asked for, before any money moves.

    • Python
    • LLM agents
    • Verification
    View Custodian on GitHub

These are independent projects and experiments, not commercial releases. None are published on Google Play yet.

About

About Anshul Labs

Anshul Labs is an independent software business based in Prayagraj, India.

We build software products, mobile applications and technology experiments, with a focus on Android, AI and practical software engineering. Work is done in the open where possible, and projects are described as they are — experiments are labelled as experiments.

The studio is intentionally small: clear scope, direct communication and careful work.
